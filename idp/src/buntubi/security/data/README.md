# breached.txt.gz

Passwords of 10 to 256 characters from the most common million in Mark Burnett's ten-million
password dataset (released into the public domain), lower-cased, one per line, sorted. Taken
from SecLists, `Passwords/Common-Credentials/xato-net-10-million-passwords-1000000.txt`.
Read by `idp/security/passwords.py` to refuse well-known passwords.
